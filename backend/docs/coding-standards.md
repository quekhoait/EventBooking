# Quy chuẩn viết code

## Python
- Tuân thủ PEP 8.
- Sử dụng type hints.
- Viết docstring cho các function/class công khai.

## Naming Convention
- `snake_case` cho functions, variables.
- `PascalCase` cho class names.
- `UPPER_SNAKE_CASE` cho constants.

## Import
- Import theo thứ tự: stdlib → third-party → local.
- Sử dụng absolute imports.

## Error Handling
- Sử dụng try-except hợp lý.
- Log errors trước khi raise.
