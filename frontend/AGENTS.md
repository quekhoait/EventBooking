# Quy tắc cho AI Agent

## Nguyên tắc chung
- Luôn thao tác tại thư mục hiện tại (`./`), không tạo file tạm.
- Giao tiếp bằng tiếng Việt.
- Khi làm việc với module nào, ưu tiên đọc tài liệu tương ứng trong thư mục `docs/`.

## Quy tắc làm việc
- Đọc kỹ `docs/architecture.md` trước khi thay đổi kiến trúc.
- Tuân thủ `docs/coding-standards.md` khi viết code.
- Cập nhật `docs/tasks.md` khi hoàn thành hoặc thêm công việc mới.
